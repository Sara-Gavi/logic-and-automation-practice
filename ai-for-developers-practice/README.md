# Express API

Una API simple creada con Express.js.

## Instalación

Asegúrate de tener Node.js instalado. Para usar pnpm, actualiza a Node.js v18+.

```bash
npm install
# o si tienes pnpm compatible: pnpm install
```

## Uso

```bash
npm start
# o pnpm start
```

La API estará disponible en http://localhost:3000

## Rutas

- `GET /`: Mensaje de bienvenida
- `GET /api/users`: Lista de usuarios de ejemplo
